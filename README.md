# NimbusProject - Student Course Planner and Prerequisite

## About Project
This is a Student Course Planner and Prerequisite project.
It helps students to plan their courses and check prerequisites before selecting subjects.

## Features
- View all courses
- Check prerequisites for each course
- Plan semester-wise courses
- Easy to use for students

## Files
- Nimbus 3190 - Main project folder with code

## How to Run
1. Open the Nimbus 3190 folder
2. Open main file
3. Compile and run
